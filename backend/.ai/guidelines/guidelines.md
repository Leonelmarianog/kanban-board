## Custom Skills

Load the relevant skill for the task:
- `/architecture-conventions` — Clean Architecture patterns, use-case isolation, repository per operation
- `/laravel-conventions` — Controllers, models, form requests, migrations, routes
- `/testing-conventions` — Pest testing patterns and organization
- `/git-conventions` — Branch naming, commit messages, PR guidelines

## Workflow Rules

- **Never create a commit** without first previewing the commit message for approval
- **Never create a pull request** without first previewing the PR contents for approval
- **Never push to GitHub** without explicit approval
- **Always check for custom skills** when working on new features or changes
